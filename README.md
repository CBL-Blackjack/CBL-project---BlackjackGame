CBL BLACKJACK GAME INSTRUCTIONS

The traditional blackjack game where the balance can be set manually.

1. Set your initial balance to start the game
2. Adjust your bet by pressing the chips
3. Click "Hit" or "Stand" to continue playing the game
4. Your balance will adjust automatically depending on the outcome of the  game
5. If you run out of money, you can always set a new balance by pressing the "Balance" button
6. Exit the game anytime

Features to test

1. Balance can't be negative
2. Cards are shuffled correctly
3. Ace is handled correctly
4. Dealer draws until 17
5. Bust (>21) is handled correctly
6. Balance updates correctly after each round
7. Score is displayed correctly
8. The result messages have the correct information
